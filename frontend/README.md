What it does

Quick setup for building React apps with TypeScript
Hot Module Replacement (HMR) – see your changes instantly
Basic ESLint rules to catch mistakes

Run it
npm install
npm run dev
App runs at: http://localhost:5173 (default Vite port)

Main Features
React – build interactive UI components
TypeScript – adds types to catch errors early
Vite – super fast build and dev server
ESLint – checks your code for mistakes

Plugins
@vitejs/plugin-react – makes React updates fast
@vitejs/plugin-react-swc – alternative plugin for fast updates

Optional
React Compiler – can make your app faster, but not included by default
Type-aware ESLint rules – extra checks for production apps
React-specific ESLint plugins: eslint-plugin-react-x and eslint-plugin-react-dom

Tests
npm test
